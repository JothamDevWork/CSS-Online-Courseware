Lesson 4: Border Radius CSS Property

The border-radius property in CSS is used to make the corners of an element rounded.

It improves the appearance of a webpage by turning sharp corners into smooth and curved edges.

The border-radius property can be applied to HTML elements such as div, img, and button.





1. 2.

Steps In Applying Border Radius CSS Property

  1. Using the previous output, In the CSS file, apply the border-radius property to the div. Start with a small value (e.g. 10px) and increase it to see how the corners become more rounded.

    You may also try percentage values (e.g. 50%) to create a circular or oval shape.

  2. Save both the HTML and CSS files, then refresh the browser to see how the border-radius property changes the shape of the element.
