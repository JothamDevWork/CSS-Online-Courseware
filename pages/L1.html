Lesson 1: How to create and connect CSS to HTML file

Knowing this is important because it controls the design of a website, like colors, fonts, and layout.

Allows us to separate the content (HTML) from the design (CSS). This makes our codes more organized!

The file extension for CSS file is ".css".

Steps In Creating And Connecting CSS file
  1. Create a folder.

  2. Open Visual Studio Code(VS code).

  3. In the Explorer Sidebar under the folder section, open the folder.

  4. Once the folder is open in VS code, create "index.html" file.

  5. Next create "style.css" file.

  6. Click index.html file, click shift + 1 then enter.

  7. Finally inside the head tag, connect the style.css file by adding <"link rel="stylesheet" href="styles.css">





ACTIVITY
