Lesson 5: Shadow Text/Box CSS Property

The border-radius property in CSS is used to make the corners of an element rounded.

It improves the appearance of a webpage by turning sharp corners into smooth and curved edges.

Both text-shadow and box-shadow use offset-x and offset-y to control the horizontal and vertical position of the shadow, while the blur-radius determines how soft or sharp the shadow edges appear. You can also customize the shadow color and even apply multiple shadows for more advanced effects.

The border-radius property can be applied to HTML elements such as div, img, and button.

Steps In Applying Shadow Text/Box

  1. Using the previous output, select the text or div element you want to style. In the CSS file, apply the text-shadow property to text. Start with small values (e.g. text-shadow: 5px 5px 5px #ffffff;) and increase the offsets or blur to see how the shadow changes.

    Apply the box-shadow property to a div or any element to create a shadow around it. Example: box-shadow: 10px 10px 60px rgba(0, 0, 0, 0.5);.

  2. Save both the HTML and CSS files, then refresh the browser to see how text-shadow and box-shadow affect the element. Experiment with different colors, offsets, and blur values to achieve the desired effect.
