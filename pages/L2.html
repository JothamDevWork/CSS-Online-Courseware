Lesson 2: Background Color CSS Property

Knowing this is important because it lets us change the background color of a webpage or specific elements.

It helps improve the look and readability of a website by making sections clear and visually appealing.

The background-color property is written in a CSS file with the .css file extension.

We will also use an HTML element called div(division) to apply background colors to different sections of the page.

Steps In Applying Background Color CSS Property

  1. Inside the index.html file, create a div element.

  2. Give the div an id and assign it a name.

  3. Select the div in CSS using the id name.

  4. Set the width to 500px and the height to 500px.

  5. Apply the background-color property to the div, for example: background-color: blue;.

  6. Save both files and refresh the browser to see the colored box.
