Lesson 3: Box Model + Padding & Margin CSS Property

The Box Model is a concept in CSS that describes how every HTML element is represented as a rectangular box. Each box is made up of four parts: content, padding, border, and margin.

Padding and margin help improve layout and readability by controlling the space inside the element (padding) and outside the border (margin).

We can apply padding and margin to HTML elements like div, p, and h1 to control their spacing and layout.
